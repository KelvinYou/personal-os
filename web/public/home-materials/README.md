# Local material references

External reference assets for the local 3D material study. These files contain no
home layout, personal reference image, generated lightmap or scene capture.

Source: [Poly Haven](https://polyhaven.com/). Its asset files are released under
[CC0](https://polyhaven.com/license). Download URLs, SHA-256 hashes, byte sizes and
verification dates are recorded in [sources.json](sources.json). Maps and HDRI
were downloaded through the public API and checked against provider MD5 values.
No asset-preview render or website artwork is redistributed here.

- Cotton Jersey: color, OpenGL normal and roughness for upholstery.
- Curly Teddy Natural: color, OpenGL normal and roughness for the rug.
- Terlenka: color, OpenGL normal and roughness for drapery.
- Rosewood Veneer 1: color, OpenGL normal and roughness for the fitted wood frame.
- Small Empty Room 1: 1K HDR environment lighting reference.

All source maps are 1024 × 1024. The indoor HDRI is an environment reference;
it is not a measured lighting capture of the owner's home. Color maps use sRGB;
normal and roughness maps remain linear/non-color. Geometry fitting, tint and
repeat settings are owned by the local scene, not by these source files.
