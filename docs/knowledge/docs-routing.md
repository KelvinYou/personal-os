# Documentation routing

The repository has several document owners rather than one undifferentiated
knowledge folder. Start with the [documentation index](../INDEX.md), then read
the smallest authoritative section for the question.

## Owner map

- System direction: `docs/VISION.md`; optional owner direction: private `data/reference/personal-direction.md`
- Settled trade-offs: `docs/DECISIONS.md`
- Unfinished work: `docs/ROADMAP.md` and `docs/plans/`
- Implementation-ready designs: `docs/design/`
- Time-bound evidence: `docs/analysis/`
- Evergreen understanding: `docs/knowledge/`

The owner determines lifecycle and freshness. A knowledge note can explain a
stable concept, but it must not become a second active roadmap, decision log,
or private data store.
