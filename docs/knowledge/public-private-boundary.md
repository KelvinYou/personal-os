# Public and private boundary

Tracked repository documentation can describe public architecture, workflows,
and reusable abstractions. Personal facts stay in the private data repository
at `data/`: daily logs, profile, finance, travel, and private idea records.

Knowledge notes may link to public owners and explain the boundary, but they
must not copy balances, targets, transactions, profile values, or other
personal facts. The [index privacy rules](../INDEX.md#privacy-and-lifecycle)
are the entry point for this check.
